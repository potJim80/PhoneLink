Phone Link setup

Once only. The phone needs to trust this Mac before it will lend it the microphone.

  1. Get the Mac’s certificate, then tap Allow.

  2. Install it.Settings › General › VPN & Device Management › Phone Link › Install
  3. Turn on trust for it.Settings › General › About › Certificate Trust Settings › Phone Link
